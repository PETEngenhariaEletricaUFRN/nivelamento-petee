# Exercícios de Algoritmos em C++

Adaptação da lista do Prof. Gustavo Guanabara (originalmente em Portugol) para C++.

## Convenções desta lista

- Use `#include <iostream>`, `<string>`, `<vector>`, `<cmath>`, `<iomanip>` e `<random>` (ou `<cstdlib>`/`<ctime>`) conforme necessário.
- Leitura: `std::cin >> x;` para números e palavras soltas; `std::getline(std::cin, nome);` para nomes com espaços (atenção ao `std::cin.ignore()` após ler um número).
- Saída: `std::cout`. Para fixar casas decimais use `std::fixed << std::setprecision(n)`.
- Números reais: use `double`. O separador decimal na digitação é o ponto (`1850.45`), não a vírgula.
- Estruturas: "enquanto" = `while`, "faça enquanto" = `do { } while ();`, "para" = `for`, "vetor" = `std::vector<T>` (ou array `T v[N]`), "procedimento" = função `void`, "função" = função com retorno.
- Sorteio: `std::mt19937` com `std::uniform_int_distribution` (ou `rand()` com `srand(time(0))`).
- Compilação sugerida: `g++ -std=c++17 -Wall -Wextra programa.cpp -o programa`
- Sempre que o enunciado pedir "algoritmo", "aplicativo" ou "lógica", entenda como "programa em C++".
