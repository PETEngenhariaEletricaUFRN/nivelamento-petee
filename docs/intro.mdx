# Introdução aos Exercícios

Bem-vindo à seção de prática! Aqui você encontrará listas de exercícios estruturadas.

## Como funcionam os exercícios

A ideia é unir a teoria incorporada até aqui com a prática em bancada e simulações. Os exercícios são divididos por níveis de dificuldade e cobrem desde conceitos fundamentais até conceitos de conhecimento intermediários.

## O que você vai precisar

Quanto as ferramentas de desenvolvimento que serão necessárias recomenda-se usar:

  * Para simulação de circuitos com microcontroladores:
    - [Tinkercad](https://www.tinkercad.com/)
    - [Wokwi](https://wokwi.com/)

  * Para simulação de circuitos analógicos:
    - [Falstad](https://www.falstad.com/circuit/circuitjs.html)

  * Para Programação de microcontroladores como ESP32/Arduino:
    - [Arduino IDE](https://docs.arduino.cc/software/ide/)
    - [Vscode com uso do Platformio](https://code.visualstudio.com/) -[ guia de instalação Platformio](https://docs.platformio.org/en/stable/integration/ide/vscode.html)

  * Para uso como repositório Git:
    - [GitHub](http://github.com/)
