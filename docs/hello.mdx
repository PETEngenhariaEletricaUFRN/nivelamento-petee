# Exercício: Suavização de Sinal PWM

Nesta prática, vamos utilizar o timer do ESP32 para gerar um sinal PWM e um filtro passivo para convertê-lo em uma tensão analógica contínua.

## Equação do Filtro

Calcule o valor do capacitor $C$ para uma frequência de corte $f_c = 10 \text{ Hz}$, dado um resistor $R = 4.7k\Omega$:

$$
f_c = \frac{1}{2\pi R C}
$$

## Código Base

Utilize o trecho abaixo como ponto de partida para configurar o PWM no ESP32:

```cpp
#include <Arduino.h>

const int pwmPin = 18;
const int frequencia = 5000;
const int canal = 0;
const int resolucao = 8; // 0 a 255

void setup() {
  ledcSetup(canal, frequencia, resolucao);
  ledcAttachPin(pwmPin, canal);
}

void loop() {
  ledcWrite(canal, 128); // 50% de Duty Cycle
}
